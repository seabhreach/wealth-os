# Archived design documents

These documents are retained as useful historical context from early project discovery. They do
not define Wealth OS v0.1.0 behaviour. The authoritative release specification is
[../MVP_SPEC.md](../MVP_SPEC.md).

- `RFC-001_Household_Aggregate.md` describes a proposed broad domain aggregate that is outside
  the delivered deterministic MVP scope.
- `WO-001_Domain_Model.md` is a completed/superseded work order whose scope excludes several
  delivered MVP capabilities.
