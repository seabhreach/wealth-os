# Wealth OS – Start Here

## Released documentation

Wealth OS v0.2.0 is a deterministic, single-household retirement-planning proof of concept with
Advisor Mode, owner-specific pension and State Pension assumptions, and opt-in Irish tax planning.
The authoritative specification for this release is [MVP_SPEC.md](MVP_SPEC.md). It defines the
implemented behaviour, calculation order, input schema, and limitations.

The reference configuration is [../data/example_household.yaml](../data/example_household.yaml).
For setup and operation, see [../README.md](../README.md).

## Historical documents

Earlier proposed domain design and work-order documents are retained in [archive/](archive/) for
historical context. They are not authoritative for v0.2.0 and must not be used to infer behaviour
outside the MVP specification.
